# Hotel Guest Satisfaction Analysis using Excel

## Project Overview
This project analyzes hotel guest feedback to understand customer satisfaction, loyalty (NPS), guest behavior, and customer acquisition performance.
The analysis was performed entirely in Microsoft Excel using Pivot Tables, Pivot Charts, KPI Cards, and Dashboard Design.

## Business Questions
- How satisfied are hotel guests?
- How has guest satisfaction changed over time?
- Which services receive the most negative feedback?
- Do Business and Vacation guests differ in satisfaction?
- Which customer acquisition sources bring the most guests?

## KPIs
- Total Guests
- Average Overall Experience
- Average NPS Rating
- % Promoters
- % Detractors
- Business Guest %
- Vacation Guest %
- Top Acquisition Source
- Most Reported Feedback Category

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Key Insights
- Guest satisfaction remained relatively stable between 3.3 and 3.8 throughout 2020–2022.										
- Nearly half of guests (47%) are Promoters.					
- Organization was the largest acquisition source.
- Room-related feedback was the most common complaint category.
- Guests visiting for Business purpose are highest contributors to promote the hotel						

## Recommendations
- Improve room facilities and maintenance.
- Continue monitoring guest satisfaction quarterly.
- Focus marketing efforts on high-performing acquisition channels.
- Convert Passive guests into Promoters through service improvements.
